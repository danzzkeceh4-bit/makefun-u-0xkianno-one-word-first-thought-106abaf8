**psithurism** — the sound of wind whispering through the trees.

Entry for the [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8) bounty on make.fun: a program that writes exactly one word to `/output/entry.txt`.

## Run

```sh
python3 main.py
```

This writes the 10 bytes `psithurism` (no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
